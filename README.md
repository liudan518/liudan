# 论文与科研主页 / Research Papers

航空发动机与燃气轮机的故障诊断、异常检测和性能预测研究。

Research on fault diagnosis, anomaly detection and performance prediction for aero-engines and gas turbines.

本目录汇总 [liudan518 的公开仓库](https://github.com/liudan518?tab=repositories)中的 **8 篇独立论文**，提供论文完整标题、科研主页、PDF、项目仓库、发表信息、DOI 和引文入口。科研主页和仓库内的论文 PDF 均可公开访问，无需登录。

Research webpage for **A novel majority-oriented over-sampling technique and its application in imbalanced anomaly detection of aero-engines**.

- Website: https://liudan518.github.io/liudan/

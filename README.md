# MOOST: Aero-Engine Anomaly Detection

Research webpage for **A novel majority-oriented over-sampling technique and its application in imbalanced anomaly detection of aero-engines**.

- Website: https://liudan518.github.io/liudan/
- Paper DOI: https://doi.org/10.1016/j.ress.2026.112377
- Languages: English and Chinese, with an in-page language switch.

The website is a static HTML page with six local figure images. To serve it with GitHub Pages, select **Settings → Pages → Deploy from a branch → main → / (root)**.

Figures and data are reproduced from the original paper, as credited on the webpage.
